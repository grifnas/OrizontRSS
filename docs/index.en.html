Features

  • feed folders, tags, favorites, and a “Read later” list;
  • integrated reader with arrow-key navigation and speech output;
  • search, OPML import, backup, and sharing;
  • Gemini conversations and DeepL translation, enabled explicitly by the user;
  • Romanian, English, Spanish, French, German, Portuguese, Hungarian, and Italian interface.

Interface previews

These images use demonstration data and show the main areas of the application. They contain no personal feeds or API keys.

Accessibility and privacy

The application is keyboard-accessible and tested with JAWS and NVDA. Feeds, articles, and API keys stay in the local Windows profile; text is sent to Gemini or DeepL only when the user explicitly starts that action.
