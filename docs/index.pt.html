Orizont RSS

Leitor RSS acessível para Windows, criado para uso com teclado e leitores de ecrã.

Română · English · Español · Français · Deutsch · Português · Magyar · Italiano

Versão 1.5.3

Versão estável e autónoma para Windows x64. Não é necessária uma instalação separada do .NET Runtime.

Instalar o Orizont RSS (recomendado)

Transferir a versão portátil (ZIP)

Verifique o hash SHA-256 apresentado na página do Release antes de instalar.

Funcionalidades

  • pastas de feeds, etiquetas, favoritos e uma lista «Ler mais tarde»;
  • leitor integrado com navegação pelas setas e leitura de voz;
  • pesquisa, importação OPML, cópias de segurança e partilha;
  • conversas Gemini e tradução DeepL, ativadas explicitamente pelo utilizador;
  • interface em romeno, inglês, espanhol, francês, alemão, português, húngaro e italiano.

Pré-visualizações da interface

Estas imagens usam dados de demonstração e mostram as principais áreas da aplicação. Não contêm feeds pessoais nem chaves de API.

Acessibilidade e privacidade

A aplicação pode ser controlada pelo teclado e foi testada com JAWS e NVDA. Os feeds, artigos e chaves API permanecem no perfil local do Windows; o texto só é enviado para o Gemini ou o DeepL quando o utilizador inicia explicitamente a ação.
