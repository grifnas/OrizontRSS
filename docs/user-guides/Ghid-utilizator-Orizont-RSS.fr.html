Guide de l'utilisateur d'Orizont RSS

1. Première ouverture

Orizont RSS s’ouvre dans la fenêtre principale. Si aucun flux n’est présent, utilisez le menu Flux pour en ajouter un ou importez un fichier OPML. Les données, les paramètres et les clés API configurées sont conservés dans le profil Windows ; ils ne figurent pas dans l’archive de distribution.

La langue de l'interface est choisie dans les paramètres de l'application. Le roumain, l'anglais, l'espagnol, le français, l'allemand, le portugais, le hongrois et l'italien sont disponibles. La modification est appliquée après le redémarrage de l'application. Lors d'une nouvelle installation, l'option Automatique utilise la langue Windows lorsqu'elle est prise en charge et l'anglais dans le cas contraire.

Accessibilité : L'interface est compatible avec les lecteurs d'écran. Le moteur vocal choisi est facultatif et lit le contenu uniquement sur commande.

2. Structure de la fenêtre principale

La fenêtre contient trois panneaux, suivis de la barre d'état :

  1. Flux : le dossier affiché, Lire maintenant, le filtre des sources qui nécessitent une attention particulière et la liste des flux.
  2. Article : la recherche, le bouton Filtrer les articles et la liste des résultats.
  3. Contenu de l'article : un champ en lecture seule, navigable avec les flèches.

Navigation entre les panneaux

Utilisez-le F6 pour le prochain panneau et Shift+F6 pour le précédent. Les commandes directes sont Ctrl+1, Ctrl+2 et Ctrl+3. Tab cela ne passe que par des contrôles utiles.

Barre d'état

La barre d'état décrit le panneau actuel, le nombre d'éléments, les opérations en cours et les erreurs. Un lecteur d'écran peut le lire avec sa commande de barre d'état, si elle est disponible.

Les sons de l’application se choisissent dans les Paramètres, sous « Thème sonore » : Sons de Windows, Interface, Clochettes ou Orizont. Les thèmes ont des sons pour les nouveaux articles, les erreurs, le changement de dossier, le début et la fin des listes, les favoris, la suppression, les réponses de l’IA et les traductions, ainsi que la synchronisation NewsBlur. « Tester le son » joue le thème choisi, et « Activer les alertes sonores » active ou désactive tous les sons.

3. Flux et dossiers

Ajouter un flux

Choisissez Flux, puis Ajouter un flux. Saisissez le nom et l'adresse RSS et choisissez un dossier existant ou créez-en un nouveau. Orizont RSS ne permet pas d'ajouter la même adresse plus d'une fois.

Dans la boîte de dialogue Ajouter un flux ou Modifier le flux, l’option À l’ouverture de l’article définit la façon dont s’ouvrent les articles de ce flux : Utiliser le réglage général, Mode standard dans la fenêtre principale, Lecteur Orizont ou Mode lecture du navigateur, dans une fenêtre externe. Le même choix existe dans les Paramètres, sous Ouverture par défaut des articles.

Vue d'un dossier

Lorsque vous choisissez un dossier, la liste Articles combine les articles de tous ses flux et les classe du plus récent au plus ancien. Le lecteur d'écran annonce la source de chaque article et la barre d'état indique le nombre de flux et les totaux d'articles.

Découvrir de nouvelles sources

Depuis le menu Flux, vous pouvez trouver de nouvelles sources de deux façons. Trouver des flux sur un site accepte l'adresse d'un site, d'un article, d'une chaîne YouTube, d'un subreddit, d'un projet GitHub ou d'un profil Mastodon. L'application recherche les flux, les vérifie automatiquement et n'affiche que ceux qui fonctionnent, avec le nombre d'articles et la date du dernier article ; les flux de commentaires sont signalés et apparaissent à la fin. Rechercher des flux par sujet propose le catalogue vérifié, filtré par catégorie, et le bouton Rechercher sur Internet, qui utilise le service Feedly : les mots recherchés sont envoyés à Feedly uniquement lorsque vous appuyez sur le bouton, et les résultats sont vérifiés avant d'être affichés. Vous pouvez aussi saisir un domaine, par exemple heise.de. Dans les deux fenêtres, le premier résultat reçoit le focus et Ajouter un flux vérifié ajoute le flux choisi.

Flux qui nécessitent une attention particulière

Le bouton du panneau Flux affiche les flux qui comportent au moins trois erreurs consécutives ou qui n'ont pas reçu d'articles depuis plus de 90 jours. Lorsque le filtre est actif, le même bouton renvoie à tous les flux.

Doublons

L’option Vérifier et nettoyer les doublons fusionne les doublons connus uniquement après confirmation. Pour les sources avec des adresses différentes mais des articles quasiment identiques, l'utilisateur choisit le flux conservé.

4. Lire et organiser les articles

Sélectionnez un élément et appuyez sur Enter pour le contenu. Presse Escape pour revenir au même élément ou, s'il a disparu suite à une action, à l'élément suivant à la même position.

Actions rapides

  • R marquer lu ou non lu.
  • F ajouter ou supprimer des favoris.
  • L ajouter ou supprimer de Lire plus tard.
  • Delete supprimer les éléments sélectionnés après confirmation.
  • Shift+F10 ouvrir le menu contextuel pour les balises, le déplacement, la copie et d'autres actions.

Étiquettes

Lors de l'étiquetage, vous pouvez choisir les étiquettes déjà créées ou en insérer une nouvelle. La boîte de dialogue permet également la suppression permanente des balises de tous les articles.

Ouvrir sans publicités dans le navigateur

Dans le menu contextuel de l'article ou du contenu, choisissez Ouvrir l'article en mode Lecture. Orizont envoie la page au mode Lecture de Microsoft Edge, qui supprime les publicités, les barres latérales et la navigation inutile sur les pages compatibles. Ouvrir la page d'origine dans le navigateur reste disponible séparément. Pour le texte intégral, l'application ne conserve que l'article : les menus, les listes latérales et les sections de commentaires ne sont pas inclus. Si la page n'est pas reconnue comme un article, l'ancienne méthode d'extraction est utilisée.

L’option Mode lecture du navigateur, dans une fenêtre externe ouvre l’article en mode lecture de Microsoft Edge, dans une fenêtre séparée, si la page est compatible. Si Microsoft Edge n’est pas installé, l’article s’ouvre dans le navigateur par défaut.

Dans le lecteur Orizont, le raccourci par défaut Ctrl+Shift+F8 permet de passer du texte simple à WebReader. Le menu contextuel ou le menu Lecteur permet d’enregistrer l’article affiché au format TXT ou RTF dans le dossier choisi dans les paramètres de l’application. Le document conserve la source et, pour une traduction, le fournisseur.

Dans WebReader, l’article conserve la structure trouvée par SmartReader : titres, listes, citations et liens se parcourent avec les touches de navigation du lecteur d’écran (H, L, Tab). La touche Applications et Maj+F10 ouvrent le menu des commandes du lecteur dans les deux modes.

Un épisode de podcast, c’est-à-dire un article avec un fichier audio joint, se lit dans le lecteur Orizont, en mode texte : C lance ou met en pause la lecture, Z et B reculent et avancent de 30 secondes, et X et V de 5 secondes. S règle la vitesse (0,5–2), P la tonalité (0,5–1,5), et D télécharge l’épisode. La vitesse et la tonalité se modifient indépendamment.

Au-dessus du texte, le lecteur affiche les boutons du podcast : -30 s, -5 s, Lire le podcast, +5 s, +30 s, Vitesse de lecture, Hauteur de lecture et Télécharger le podcast. Ils font la même chose que les touches et n’apparaissent que pour les articles avec podcast. Le volume du podcast se modifie avec Alt+↑ et Alt+↓, par pas de 5 %, de 0 % à 300 %. Le volume est indépendant du volume de Windows, et les valeurs au-delà de 100 % peuvent déformer le son. Depuis la liste des articles ou le menu Article du texte, vous pouvez lancer ou mettre en pause le podcast sans ouvrir le lecteur. Fermer le lecteur arrête la lecture seulement si le podcast appartient à l’article fermé.

Les liens YouTube ne sont pas téléchargés pour la lecture, car la page de visionnage demande d’abord votre consentement. Le lecteur affiche la description de la vidéo issue du flux et une note. Pour regarder la vidéo, choisissez « Ouvrir la page d’origine dans le navigateur » dans le menu du lecteur, puis acceptez le consentement directement dans le navigateur.

La barre d’état, avec les messages de l’application, se lit en mode texte. Dans WebReader, le focus reste sur la page de l’article et les messages d’état ne sont pas annoncés ; les résultats des opérations (par exemple la traduction) sont visibles en mode texte.

5. Recherche et filtres

Ctrl+F ou F3 déplace le focus vers les éléments de recherche. La recherche vérifie le titre, la source et le contenu RSS. Escape effacer le texte de recherche.

Ctrl+Shift+F ouvre la boîte de dialogue Filtres d'éléments. Vous pouvez choisir le statut, la période et le tag. Les modifications sont appliquées uniquement via le bouton Appliquer ; L'évasion se ferme sans modifications.

Ctrl+Shift+U afficher tous les articles non lus de toutes les sources.

6. Lecture vocale SAPI5, eSpeak NG et Gemini

Orizont RSS peut utiliser les voix SAPI5 de Windows, le moteur local eSpeak NG ou 30 voix Gemini TTS en ligne. SAPI5 et eSpeak fonctionnent localement. Avec Gemini TTS, le texte est envoyé à Google et peut consommer le quota ou les crédits de l'API.

Configuration vocale

Ouvrez les paramètres de l'application et la section Lecture vocale. Choisissez SAPI5, eSpeak NG ou Gemini TTS, puis la voix, la vitesse et le volume. Gemini TTS utilise la clé enregistrée dans les paramètres IA. Testez la voix, puis enregistrez. Pour eSpeak NG, le volume couvre toute la plage du moteur ; si la voix est trop forte, baissez le volume avec le même réglage.

Commandes de lecture

  • F9 lire la sélection du contenu ; s'il n'y a pas de sélection, lisez le titre, la source, la date et l'article complet affichés.
  • F9 faites une pause ou continuez la lecture.
  • Escape arrête de lire.
  • Le menu vocal et le menu contextuel contiennent également la commande Lire à partir du curseur.
  • Shift+F9: ouvre les paramètres vocaux.
  • F11: agrandit ou restaure la fenêtre.

La lecture ne démarre pas automatiquement lors du changement de focus, afin de ne pas chevaucher le lecteur d'écran.

Si l'application est ouverte depuis longtemps ou si le Windows est revenu du mode veille, chaque nouvelle lecture recrée le moteur SAPI5 et réapplique la voix, la vitesse et le volume. Si la première initialisation échoue, l'application réessaye automatiquement une fois et affiche l'état dans la barre d'état.

7. Fournisseurs d’IA, conversations et traduction

Gemini, OpenAI, Mistral et DeepSeek sont facultatifs. Dans Paramètres → Intelligence artificielle, vous pouvez saisir une clé API pour chacun et choisir le fournisseur par défaut. Vous pouvez poursuivre une conversation au sujet d’un article, puis la copier, l’enregistrer ou la partager. Résumé, Traduction, Explication et Idées principales demandent une réponse dans la langue de l’interface.

Google Translate est distinct des conversations IA : il utilise un service en ligne non officiel sans clé API et demande confirmation avant l’envoi du texte. DeepL nécessite votre clé API. Une traduction copiée, enregistrée ou partagée indique le fournisseur et contient l’adresse de l’article source.

Dans la fenêtre de conversation, F9 lit la sélection ou toute la conversation avec la voix configurée. F9 met en pause ou reprend et Escape arrête la lecture. Le menu contextuel permet aussi de lire à partir du curseur.

Orizont RSS affiche l'état de la demande et un message clair si le service ne répond pas, la clé est rejetée ou la connexion n'est pas disponible. Dans la fenêtre principale, Escape arrête une requête d'IA en cours. Si une réponse de Gemini atteint la limite de longueur, le texte reçu est conservé, accompagné d'une note qui le signale.

8. Importation, sauvegarde et nettoyage

OPML

Depuis le menu Flux, vous pouvez importer ou exporter un fichier OPML. L'importation évite les adresses déjà existantes. À l'export, les flux non organisés sont placés à la racine du fichier, comme dans les autres lecteurs RSS.

Sauvegarde

La sauvegarde comprend les flux, les articles, les dossiers, les étiquettes, les états, les notes IA et les préférences non sensibles. Elle ne contient ni les clés API ni la session NewsBlur.

Anciens articles

Le nettoyage automatique est configurable. Les éléments Favoris et Lire plus tard sont protégés. L'application mémorise les articles supprimés par la règle de vieillissement et ne les réimporte pas lors de la prochaine mise à jour. Les articles restent dans l'application même après avoir disparu du flux du site ; seuls le nettoyage automatique ou la suppression manuelle les retirent.

9. État, erreurs et dépannage

Ctrl+Shift+H état d'ouverture et historique des erreurs. Le texte peut être lu avec les flèches, copié ou enregistré pour le diagnostic.

Si la voix n'apparaît pas

Vérifiez si le synthétiseur est installé en tant que voix SAPI5 pour la même architecture Windows. Redémarrez Orizont RSS après avoir installé une nouvelle voix.

Si la mise à jour prend beaucoup de temps

La barre d'état affiche la progression. Escape peut arrêter le processus et mettre fin à la connexion en cours, en conservant les données déjà reçues. Dans le menu Flux, vous pouvez réessayer uniquement les sources qui ont généré une erreur. Les flux sont téléchargés en parallèle : un site lent ne retarde plus les autres. Les flux qui n'ont pas changé depuis la dernière mise à jour ne sont pas téléchargés à nouveau.

Si le guide ne s'ouvre pas

Vérifiez que le fichier Ghid-utilizator-Orizont-RSS.html et les guides traduits se trouvent à côté de Orizont.exe. Extrayez l'intégralité de l'archive ZIP, pas seulement l'exécutable.

Si une erreur inattendue se produit

L’application arrête la commande en cours, affiche un message accessible et tente d’enregistrer un rapport technique dans le dossier local de diagnostic. Ce rapport peut contenir des détails sur l’erreur : vérifiez-le avant de le partager et ne divulguez ni clés API ni autres données sensibles. Fermez puis rouvrez l’application avant de réessayer.

11. Liste des raccourcis

  • F1: aide et raccourcis.
  • F6 et Shift+F6: panneau suivant ou précédent.
  • Ctrl+1, Ctrl+2, Ctrl+3: Flux, Articles, Contenu.
  • Ctrl+Shift+1: sélecteur de dossiers.
  • Ctrl+Shift+2: articles combinés du dossier sélectionné.
  • Ctrl+4: Lisez maintenant.
  • Ctrl+F ou F3: recherche dans les articles.
  • Ctrl+Shift+F: filtrer les éléments.
  • Ctrl+Shift+U: tous non lus.
  • Ctrl+Shift+R: le texte intégral de l'article.
  • Ctrl+Shift+H: état et historique des erreurs.
  • F9: lire à haute voix.
  • F9: mettre en pause ou reprendre la voix.
  • Escape: coupe la voix.
