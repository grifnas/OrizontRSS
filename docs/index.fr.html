Orizont RSS

Lecteur RSS accessible pour Windows, conçu pour le clavier et les lecteurs d’écran.

Română · English · Español · Français · Deutsch · Português

Version 1.5.3

Version stable et autonome pour Windows x64. L’installation séparée du .NET Runtime n’est pas nécessaire.

Installer Orizont RSS (recommandé)

Télécharger la version portable (ZIP)

Vérifiez la somme SHA-256 affichée sur la page du Release avant l’installation.

Fonctions

  • dossiers de flux, étiquettes, favoris et liste « À lire plus tard » ;
  • lecteur intégré avec navigation par flèches et lecture vocale ;
  • recherche, importation OPML, sauvegarde et partage ;
  • conversations Gemini et traduction DeepL, activées explicitement par l’utilisateur ;
  • interface en roumain, anglais, espagnol, français, allemand et portugais.

Accessibilité et confidentialité

L’application est utilisable au clavier et testée avec JAWS et NVDA. Les flux, les articles et les clés API restent dans le profil Windows local ; le texte n’est envoyé à Gemini ou DeepL que lorsque l’utilisateur lance explicitement l’action.
