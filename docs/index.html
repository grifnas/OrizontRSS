Orizont RSS

Cititor RSS accesibil pentru Windows, proiectat pentru tastatură și cititoare de ecran.

Versiunea 1.5.3

Versiune stabilă Windows x64, autonomă: nu necesită instalarea separată a .NET Runtime.

Descarcă ultima versiune

Verifică suma SHA-256 afișată în pagina Release-ului înainte de instalare.

Funcții

  • organizarea feedurilor în foldere, etichete, favorite și lista „Mai târziu”;
  • cititor integrat cu navigare prin săgeți și citire vocală;
  • căutare, import OPML, backup și partajare;
  • conversații Gemini și traducere DeepL activate explicit de utilizator;
  • interfață în română, engleză, spaniolă, franceză, germană și portugheză.

Accesibilitate și confidențialitate

Aplicația este controlabilă din tastatură și verificată cu JAWS și NVDA. Feedurile, articolele și cheile API rămân în profilul local Windows; textul este trimis către Gemini sau DeepL numai la comanda explicită a utilizatorului.
