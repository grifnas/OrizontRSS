# Orizont RSS 1.5.2 — mod Citire al browserului

Această versiune restaurează opțiunea distinctă de deschidere a articolului în modul Citire al browserului.

- meniul contextual al articolelor și meniul contextual din conținut oferă acum separat:
  - cititorul integrat Orizont;
  - modul Citire Microsoft Edge (Immersive Reader), când pagina este compatibilă;
  - pagina originală în browserul implicit;
- dacă Microsoft Edge nu este instalat, comanda modului Citire deschide articolul normal în browserul implicit și anunță fallback-ul;
- validarea adreselor rămâne limitată la adrese web HTTP și HTTPS.

Versiunea nu modifică articolele, feedurile sau cheia API Gemini salvate local.
