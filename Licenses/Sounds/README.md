# Sunetele temelor sonore din Orizont RSS

Toate sunetele din `Sounds` (în sursă: `Assets/Sounds/themes`) pot fi distribuite liber împreună cu Orizont RSS.

## Interfață — sunete Kenney

- Sursa: Kenney, „Interface Sounds”, https://opengameart.org/content/interface-sounds (și https://kenney.nl)
- Licență: CC0 1.0 (domeniu public), https://creativecommons.org/publicdomain/zero/1.0/
- Creditarea „Kenney.nl” este opțională; o păstrăm din respect pentru autor.

## Clopoței — sunete Robin Lamb și HaelDB

- Sursa: Robin Lamb, „UI Sound Effects (Button Clicks, User Feedback, Notifications)”, https://opengameart.org/content/ui-sound-effects-button-clicks-user-feedback-notifications, realizate din bibliotecile de domeniu public VCSL și VSCO 2 CE.
- Sunetul „sync-done” din această temă: HaelDB, „UI Sounds”, https://opengameart.org/content/ui-sounds-0
- Licență: CC0 1.0 (domeniu public) pentru ambele pachete.

## Orizont — sunete proprii

- Sunete originale, sintetizate pentru Orizont RSS; fac parte din proiect și urmează licența acestuia (GNU GPL 3.0 sau ulterioară).

Toate fișierele au fost convertite la WAV PCM 16 biți, mono, 44,1 kHz; liniștea de la început și de la sfârșit a fost tăiată, iar volumul a fost adus la același nivel.
