1. First opening

Orizont RSS starts directly in the main window. If there are no feeds, use the Feeds menu, the Add feed option, or import a OPML file. Gemini data, settings and key are kept in Windows account profile; they are not included in the distribution archive.

The language of the interface is chosen from Application Settings. Romanian, English, Spanish, French and German are available. The change is applied after restarting the application. On a fresh install, the Automatic option uses the Windows language when supported and English otherwise.

Accessibility: The interface is compatible with screen readers. The selected speech engine is optional and reads content only on command.

2. Structure of the main window

The window contains three panels, followed by the status bar:

  1. Feeds: the displayed folder, Read now, the filter for sources that require attention, and the list of feeds.
  2. Articles: the search, the Filter articles button and the list of results.
  3. Article Content: a read-only field, navigable with the arrows.

Navigating between panels

Use it F6 for the next panel and Shift+F6 for the previous one. Direct orders are Ctrl+1, Ctrl+2 and Ctrl+3. Tab it only goes through useful checks.

Status bar

The status bar describes the current panel, number of items, operations in progress and errors. A screen reader can read it using its status-bar command, if available.

3. Feeds and folders

Adding a feed

Choose Feeds, then Add feed. Enter the name and address RSS and choose an existing folder or create a new one. Orizont RSS does not allow adding the same address more than once.

Folder view

When you choose a folder, the Articles list combines articles from all its feeds and orders them from newest to oldest. The screen reader announces each article source, while the status bar reports the number of feeds and article totals.

Discovering new sources

You can search for feeds by topic in the verified catalog or ask the app to find the feeds declared by a specific site.

Feeds that need attention

The button in the Feeds panel shows feeds that have at least three consecutive errors or haven't received articles in more than 90 days. When the filter is active, the same button returns to all feeds.

Duplicates

The Check and Clean Duplicates option merges known duplicates only after confirmation. For sources with different addresses but almost identical articles, the user chooses the preserved feed.

4. Reading and organizing articles

Select an item and press Enter for content. Press Escape for returning to the same item or, if it has disappeared due to an action, to the next item at the same position.

Quick actions

  • R mark read or unread.
  • F add or remove from Favorites.
  • L add or remove from Read Later.
  • Delete delete selected items after confirmation.
  • Shift+F10 open context menu for tags, move, copy and other actions.

Labels

When labeling, you can choose the already created labels or you can insert a new one. The dialog also allows permanent deletion of tags from all articles.

Opening without ads in the browser

From the article or content context menu, choose Open the article in Reading mode. Orizont sends the page to Microsoft Edge Reading mode, which removes ads, sidebars and unnecessary navigation on compatible pages. Open the original page in the browser remains available separately.

5. Search and Filters

Ctrl+F or F3 moves focus to search items. Search verifies title, source and content RSS. Escape clear the search text.

Ctrl+Shift+F opens the Item Filters dialog. You can choose the status, period and tag. Changes are applied only through the Apply button; Escape closes without changes.

Ctrl+Shift+U show all unread articles from all sources.

6. SAPI5, eSpeak NG and Gemini speech

Orizont RSS can use SAPI5 voices registered in Windows, the local eSpeak NG engine, or 30 online Gemini TTS voices. SAPI5 and eSpeak work locally. With Gemini TTS, the text being read is sent to Google and may consume API quota or credits.

Voice configuration

Open Application Settings and the Speech section. Choose SAPI5, eSpeak NG or Gemini TTS, followed by the voice, rate and volume. eSpeak also provides a pitch control. Gemini TTS uses the key saved in AI Settings. Test the voice and then choose Save.

Reading commands

  • F9 / F9 / Ctrl+Alt+V read the selection from the content; if there is no selection, read the title, source, date and full article displayed.
  • F9 / F9 / Ctrl+Alt+P pause or continue reading.
  • Escape / Escape / Ctrl+Alt+S stop reading.
  • The Voice menu and context menu also contain the Read from Cursor command.
  • Shift+F9: open Voice settings.
  • F11: maximize or restore the window.

Reading does not start automatically on focus change, so as not to overlap the screen reader.

SAPI5 is reinitialized automatically after sleep when necessary. eSpeak NG synthesizes locally and supports the same start, pause, resume and stop commands. The active engine reports its state in the status bar.

7. Gemini and the AI conversations

Gemini is optional and requires a user configured API key. The entire displayed content of the article is included in the AI ​​question. The conversation can continue and can be copied, saved, exported or sent in its entirety. The commands Summary, Translation, Explanation and Main Ideas prompt for the response in the language of the interface.

In the conversation window, F9 / F9 / Ctrl+Alt+V reads the selection or the entire conversation using the configured voice. F9 / F9 / Ctrl+Alt+P pauses or resumes, and Escape / Escape / Ctrl+Alt+S stops reading. The context menu also provides reading from the cursor.

Orizont RSS displays the status of the request and a clear message if the service is not responding, the key is rejected or the connection is not available.

8. Import, Backup and Cleanup

OPML

From the Feeds menu you can import or export a OPML file. The import avoids already existing addresses.

Backup

The backup includes AI's feeds, articles, folders, tags, statuses, and notes. Secret keys are not exported in the clear.

Old articles

Automatic cleaning is configurable. Favorites and Read Later items are protected. The application remembers articles removed by the aging rule and does not import them again on the next update.

9. Status, Errors and Troubleshooting

Ctrl+Shift+H open status and error history. The text can be read with the arrows, copied or saved for diagnosis.

If the voice does not appear

For SAPI5, check that the synthesizer is installed for the same Windows architecture. eSpeak NG needs no voice installation; if its list is missing, download the complete Orizont RSS distribution again.

If the update takes a long time

The status bar shows the progress. Escape can stop the process and terminate the current connection, keeping the data already received. From the Feeds menu you can retry only the sources that gave an error.

If the guide does not open

Check that the Ghid-utilizator-Orizont-RSS.html file and translated guides are next to Orizont.exe. Extract the entire ZIP archive, not just the executable.

If an unexpected error occurs

The application stops the current command, displays an accessible message, and attempts to save a technical report to the local data diagnostic subfolder. Report does not include key Gemini. Close and reopen the application before repeating the operation.

11. List of shortcuts

  • F1: help and shortcuts.
  • F6 and Shift+F6: next or previous panel.
  • Ctrl+1, Ctrl+2, Ctrl+3: Feeds, Articles, Content.
  • Ctrl+Shift+1: folder selector.
  • Ctrl+Shift+2: combined articles from the selected folder.
  • Ctrl+4: Read now.
  • Ctrl+F or F3: search in articles.
  • Ctrl+Shift+F: filter items.
  • Ctrl+Shift+U: all unread.
  • Ctrl+Shift+R: the full text of the article.
  • Ctrl+Shift+H: status and error history.
  • F9 / F9 / Ctrl+Alt+V: read aloud.
  • F9 / F9 / Ctrl+Alt+P: pause or resume voice.
  • Escape / Escape / Ctrl+Alt+S: mutes the voice.
